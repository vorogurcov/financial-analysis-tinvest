# Задача 2. Объём, цена и краткосрочная волатильность

Пункт 2 плана из `README.md`: исследование влияния торговых объёмов на динамику цен и краткосрочную волатильность акций.

Выборка, лог-доходность, рублёвый оборот и отсечение скачков заданы в `plans/task_1.md` и здесь не переопределяются. Расчёт начинается с `PanelFrame` включённых акций.

## 1. Цель

Оценить, как аномальный торговый оборот связан с величиной дневного движения цены в тот же день и с реализованной волатильностью следующих пяти торговых дней.

Одинаковый знак большого оборота на росте и на падении ожидаемо слабее связан с направленной доходностью, чем с её модулем. Поэтому основные модели объясняют `|r_t|` и будущую пятидневную волатильность. Модель направленной доходности считается рядом с ними и кладётся в ту же таблицу коэффициентов, чтобы сравнение было на одном масштабе.

Коэффициент панельной регрессии — мера связи при фиксированных эффектах тикера, а не оценка торгового правила.

## 2. Общие соглашения

Окружение этого пункта: зависимости ставим и запускаем через uv. Перед командами активируем виртуальное окружение: `.venv/scripts/activate`.

Действуют соглашения `plans/task_1.md`: токен только из `.env`, свечи дневные, объём в лотах, оборот `volume * lot * close`, результаты в каталоге с меткой времени, CSV utf-8-sig, рисунки dpi 160, подписи графиков по-русски, бэкенд `Agg`.

Нужны `statsmodels` (формула МНК и HC1). `scipy` уже появляется в пункте 1 и используется здесь для Спирмена.

Запуск — тот же `python -m tinvest.research`. После анализа распределения вызывается анализ объёма. Отдельной команды у пункта нет.

## 3. Границы

В регрессии участвуют только тикеры из панели пункта 1, у которых не меньше 100 строк с одновременно непустыми `abn_volume`, `abs_return`, `abs_return_lag`, `rv_5` и `future_rv_5`. Остальные включённые тикеры остаются в описательных таблицах пункта 1 и попадают в `task2_excluded.csv` с причиной `too_few_volume_rows`.

Нулевые и отрицательные обороты не входят в модели: `abn_volume` для них NaN. Ценовой ряд при этом не выбрасывается.

Дневной бар — рабочее разрешение этого пункта. Минутные свечи для краткосрочной волатильности не требуются: короткое окно задаётся пятью следующими дневными доходностями и дневным размахом high–low. Это сохраняет одно окно истории с пунктом 1 (около трёх лет дневных баров на имя).

## 4. Величины на баре

Все скользящие окна считаются внутри тикера, по времени, без подглядывания вперёд. `min_periods` указан явно.

| Колонка | Определение |
| --- | --- |
| `turnover` | `volume * lot * close` |
| `log_turnover` | `ln(turnover)` при `turnover > 0`, иначе NaN |
| `abn_volume` | `log_turnover` минус медиана `log_turnover` по окну 21 бар, заканчивающемуся в `t`, `min_periods = 15` |
| `abs_return` | `|log_return|` |
| `abs_return_lag` | `abs_return` предыдущего бара того же тикера |
| `log_return_lag` | `log_return` предыдущего бара |
| `rv_5` | `std(r_{t-4} … r_t, ddof=1) * sqrt(252)` при пяти непустых доходностях, иначе NaN |
| `future_rv_5` | `std(r_{t+1} … r_{t+5}, ddof=1) * sqrt(252)` при пяти непустых доходностях, иначе NaN |
| `range` | `(high - low) / close` |

Медиана в `abn_volume` берётся по окну, которое кончается текущим баром и включает его. Для описательной связи «оборот сегодня ↔ движение сегодня» это согласованное состояние на закрытии дня `t`. В модели будущей волатильности признак `abn_volume_t` известен на закрытии `t`, а отклик собран только из `r_{t+1}…r_{t+5}`.

Последние пять дат каждого тикера имеют пустой `future_rv_5` и в модель B не входят.

## 5. Модели

Оценка — МНК по формуле `statsmodels`, ковариация HC1. Фиксированный эффект тикера — дамми `C(ticker)` в формуле (база выбирается библиотекой).

Перед оценкой непрерывные переменные, которые входят в сравнение силы связи, стандартизуются внутри тикера по всей его оценочной выборке: вычитается среднее и деление на `std(ddof=1)`. Стандартизация нужна, чтобы коэффициенты A, B и C стояли в одних единицах. Она описательная и использует ту же выборку, на которой считается модель. Это не прогнозный контур пункта 5, где масштабирование подгоняется только на обучающих датах.

| Модель | Формула после внутритикерной стандартизации | Вопрос |
| --- | --- | --- |
| A | `abs_return ~ abn_volume + abs_return_lag + C(ticker)` | Связан ли аномальный оборот с величиной движения в тот же день после учёта вчерашнего модуля |
| B | `future_rv_5 ~ abn_volume + rv_5 + C(ticker)` | Связан ли оборот на закрытии `t` с волатильностью следующих пяти дней после учёта уже наблюдаемой `rv_5` |
| C | `log_return ~ abn_volume + log_return_lag + C(ticker)` | Есть ли такая же связь у знаковой доходности |

В таблицу коэффициентов попадают `abn_volume`, лаг отклика (или `rv_5` в модели B) и число наблюдений. Строки дамми тикеров в CSV не пишутся. Для каждого оставленного коэффициента сохраняются `coef`, `std_err`, `p_value`, `n`, `r_squared`, `model`.

p-value двусторонние. Знак `abn_volume` в A и B интерпретируется вместе с интервалом, без перехода на односторонний критерий после просмотра оценки.

Повторная оценка A и B выполняется после удаления строк, где сырой (до стандартизации) `abs_return` выше 99-го перцентиля объединённой оценочной выборки. Эти строки помечаются `model = A_trim` и `B_trim`. Модель C повторно не оценивается.

Дополнительно по каждому тикеру, попавшему в модель A, считается коэффициент Спирмена между `abn_volume` и `abs_return` по его строкам. В сводку идут медиана этих коэффициентов и доля тикеров с положительным коэффициентом.

## 6. Модули

| Путь | Содержание |
| --- | --- |
| `tinvest/analytics/volume.py` | `VolumeConfig`, `VolumeSummary`, `VolumeImpact` |
| `tinvest/research/__main__.py` | Вызов `VolumeImpact` сразу после распределения |

`VolumeConfig` хранит `horizon = 5`, `volume_window = 21`, `min_rows = 100`, `figure_path` для каждого из трёх рисунков (три пути, три вызова сохранения; базовый `Analysis._save` пишет один `figure_path`, поэтому класс сохраняет остальные фигуры тем же способом, что `_save`: каталог создаётся, dpi 160).

`prepare(panel)` строит столбцы раздела 4. `analyze` отбирает тикеры по `min_rows`, оценивает A–C и усечённые A/B, считает внутритикерные Спирмены. `get_summary()` возвращает коэффициенты при `abn_volume` в A, B и C, их p-value, медиану Спирмена и число тикеров в регрессии.

Пустая после фильтра панель даёт `ValueError`. Если в регрессию не вошёл ни один тикер, в каталог пишется `task2_excluded.csv` по всей выборке и `VolumeSummary` с `n_tickers = 0`, без коэффициентов и без падения процесса: пункты 3–5 всё равно запускаются. В лог при этом пишется, что модели объёма не оценены.

## 8. Проверки без сети

Файл `tests/test_task2_volume.py`.

- На синтетике `|r_t| = 0.01 * abn_volume` внутри каждого тикера при нулевом лаге коэффициент при `abn_volume` в модели A по модулю отличается от стандартизованного эталона не больше чем на `1e-6`, если ряд построен без шума. Практическая проверка с шумом: при фиксированном `seed` коэффициент положительный и p-value < 0,01 на ряде длины 400 и трёх тикерах.
- У последних пяти дат каждого тикера `future_rv_5` пустой. Сдвиг горизонта на 1 не подмешивает `r_t` в `future_rv_5`: значение на дате `t` совпадает со `std` именно `t+1…t+5`.
- Бар с `volume = 0` даёт пустой `abn_volume` и не меняет соседний `log_return`.
- Тикер с 50 валидными строками при `min_rows = 100` оказывается в `task2_excluded.csv` и не меняет коэффициенты.

## 9. Критерии приёмки

- После прогона пункта 1 команда исследования дописывает таблицы и три рисунка этого пункта в тот же каталог результатов.
- В `task2_coefficients.csv` есть модели A, B и C, а при наличии строк выше 99-го перцентиля ещё `A_trim` и `B_trim`.
- Коэффициенты A, B и C относятся к стандартизованным внутри тикера рядам, поэтому их можно сравнивать по величине напрямую.
- В модели B ни одно поле отклика не использует доходность даты `t` и более ранних. Это закреплено тестом горизонта.
- Сводка в логе содержит коэффициент `abn_volume` моделей A и B, число тикеров и медиану внутритикерного Спирмена.
- Если оценочная выборка пуста, процесс завершается без исключения и без файлов рисунков этого пункта, с заполненным `task2_excluded.csv`.

## 10. Связь с другими пунктами

`abn_volume`, `rv_5` и определение оборота отсюда использует пункт 5 как признаки. Формулы должны совпадать с разделом 4, включая окно 21 и `min_periods = 15`. Пункт 5 заново стандартизует признаки только на обучающем отрезке и не переносит внутритикерную стандартизацию этого пункта: здесь она служит сравнению коэффициентов A–C, там — прогнозу.
