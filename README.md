# Tinvest

Финансовая аналитика российского рынка на основе T-Invest API.

## План

1. Анализ распределения доходностей и волатильности российских финансовых инструментов и их зависимости от характеристик инструментов.
2. Исследование влияния торговых объёмов на динамику цен и краткосрочную волатильность акций.
3. Анализ корреляционных связей между доходностями различных финансовых инструментов и их изменения в зависимости от рыночных условий.
4. Исследование временных закономерностей финансовых показателей и проверка статистических гипотез о наличии автокорреляции и устойчивости волатильности.
5. При наличии достаточного объёма и качества данных — построение модели для прогнозирования повышенной волатильности финансовых инструментов на заданном временном горизонте.

## Окружение

Нужны Python 3.12 (`py -3`) и uv.
